## Decisions
Flow:

3. `/mcp?workflow=<id>` → tools scoped as old `--workflow`.

5. `serve.host: 0.0.0.0` → `serve.unauthenticated` in `validate`; `start` refuses.

Choices:
- `--ui-port` loses commander default: given → overrides `serve.port`.
- `--headless`, `--once`: no door, no MCP. One door.
- Schema has no `people.oidc` until Task 9 → every non-loopback host refused.

- Scope fixed at session initialize; unknown workflow → 400, no session. Claims judged over all workflows (`ToolOptions.scope`).
